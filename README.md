# devbord for Minecraft

Plugins that connect a Minecraft server to [devbord](https://devbord.com).

| Plugin | What it does |
|---|---|
| [devbord-bugreport](devbord-bugreport) | Players type `/bug <description>`; the report becomes a card with their world and position, and they hear it in the game when the bug is fixed. Paper 1.20 and newer. |

The protocol is described in [devbord-com/integrations](https://github.com/devbord-com/integrations).
